Questions? Answered.

Do I need a Microsoft/Minecraft account?

No. Luma Client works fully offline — type any username and play on cracked/offline-mode servers or singleplayer.

Is this safe to use?

Luma only modifies your local game files (mods, resource packs, options) and never touches your system outside its own folder (%APPDATA%\.lumaclient).

Will I get banned for using mods?

Luma's mod pack is client-side only (like Lunar or Badlion) — no gameplay-altering hacks are bundled by default. Always check the rules of the specific server you're joining.

What Minecraft versions are supported?

1.20.1, 1.20.4, 1.21.1 and 26.1.2 are supported out of the box, with automatic Java and Fabric setup for each.

Does the AI companion cost anything?

No — LumaAI runs on free AI models by default, with automatic fallbacks so it keeps working even under rate limits.
